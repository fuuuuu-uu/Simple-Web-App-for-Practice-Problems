# 刷題小幫手

手機用的個人刷題網頁（PWA）。**本專案只含程式，不含任何題庫**；題庫與圖片由使用者自行準備，只存在自己的裝置上，不會上傳。

## 功能
- 載入 Excel 題庫（.xlsx），檔案毀損／未選檔時顯示「檢查檔案」，程式不中斷
- 模式：練習（答完立即公布）、模擬考試（交卷後公布）、尋找（輸入題號）
- 題號清單跳題（綠＝上次答對、紅＝上次答錯）
- 「承上題／續上題」自動顯示被承上的題目
- 熟悉度標籤（知／背／算）可在作答時切換
- 錯誤次數、作答次數自動存在手機；可匯出成 Excel，下次直接載入匯出的檔案接續
- 圖片：題目圖、選項圖、解析圖（見下方檔名規則）
- 可離線使用

## Excel 格式
沒有標題列時依欄位位置讀取；有標題列時依名稱讀取（匯出的檔案有標題列）。

| 欄 | A | B | C | D | E | F | G~J | K | L | M |
|---|---|---|---|---|---|---|---|---|---|---|
| 內容 | 題號 | 圖片 | 解析 | 熟悉度 | 解答 | 題目 | 選項A~D | 錯誤次數 | 作答次數 | 承上題號 |
| 必填 | ✔ | | | | ✔ | ✔ | ✔ | | | |

- 圖片：`題`＝題目有圖、`選`＝4 個選項都是圖、`題 選`＝兩者皆有
- 解析：`1`＝有解析圖
- 熟悉度：可多個，以空白分隔，例如 `算 背`
- 承上題號：選填；沒填時，題目以「承上題／續上題」開頭會自動連到前一題

## 圖片檔名規則
選單 →「載入圖片」一次多選即可（存在手機，不需每次載入）。不分大小寫，jpg/png/webp 皆可。

| 用途 | 檔名 | 例 |
|---|---|---|
| 解析 | `p題號` | `p15.jpg` |
| 題目圖 | `q題號` | `q39.jpg` |
| 選項圖 | `q題號A`~`q題號D` | `q39A.jpg` |

要改規則，修改 `app.js` 中的 `questionImageName / optionImageName / explainImageName`。

## 部署到手機（GitHub Pages）
1. 把這個資料夾推到 GitHub repo（`.gitignore` 已排除 xlsx，避免誤傳題庫）
2. repo → Settings → Pages → Source 選 `main` 分支根目錄
3. 手機 Chrome 開啟 `https://<帳號>.github.io/<repo>/`
4. Chrome 選單 →「加到主畫面」/「安裝應用程式」
5. 開啟 App → 選單 → 載入題庫

改版後把 `sw.js` 的 `VERSION` 加 1，手機重開 App 兩次就會更新。
